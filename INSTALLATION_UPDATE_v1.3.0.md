# StromBlick v1.3.0 – Installationsanleitung

**Vor dem Update:** In der App **Einstellungen → Backup exportieren**. Nicht ohne Backup deinstallieren; die Debug-APK-Signatur kann einen direkten Versionswechsel verhindern.

1. Das ZIP-Paket `StromBlick_v1.3.0_Abschlag150_Update.zip` herunterladen und entpacken.
2. Den Inhalt des Ordners `GITHUB_UPLOAD` in `Adohadesign/stromblick` hochladen. Wichtig: Dateipfade/Unterordner beibehalten, nicht den gesamten Ordner `GITHUB_UPLOAD` als Unterordner hochladen.
3. Bei GitHub unter **Actions → Android-APK erstellen** den neuesten Build verwenden. Nach erfolgreichem Build unter **Artifacts** `StromBlick-v1.3.0-ABSCHLAG150-APK` herunterladen und die enthaltene APK installieren.
4. Prüfen: Neuer Abschlag 150 € im Dashboard; offene Standardabschläge 150 € unter Details → Abschläge; bestätigte Zahlungen unverändert.

**Kein Datenreset:** Es werden ausschließlich ursprünglich vorbereitete, nicht bezahlte 94-€-Einträge umgestellt; Messungen und Tarife bleiben erhalten.

GitHub-APK-Build sowie Start und Eingabe am Android-Handy müssen noch praktisch bestätigt werden. Ein erfolgreicher Syntax- oder Rechentest ersetzt keinen Handytest.
